# 2048 Game Implementation

## Project Description

This project is a basic implementation of the popular 2048 game. The objective of the game is to combine tiles with the same numbers to create a tile with the number 2048. The game is built using JavaScript, HTML, CSS, and SCSS, and is designed to be lightweight and easy to use.

## Technologies Used

- **JavaScript**: The core logic and functionality of the game.
- **HTML**: The structure and layout of the game interface.
- **CSS/SCSS**: Styling for the game to make it visually appealing.

## Development Methodology

The game board is represented by a two-dimensional array that is linked to the HTML for visual representation. A `Game` class was created to manage the game state, including methods for handling user input, updating the game board, and checking for win/loss conditions. This approach ensures that the game logic is separated from the presentation, making the code more modular and easier to maintain.
